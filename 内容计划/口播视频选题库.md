# 艺术圈信息差·口播视频选题库与计划表

> 定位:面向艺术生/青年艺术家的"硬核经验分享",讲美院里学不到、没正式入圈前接触不到的信息壁垒。
> 与"每日机会播报"是两条不同内容资产——播报走小红书日更冲算法基本盘,这条线走**抖音主战场+B站长尾**,周更 2 条左右,建人设权威、把路人转成铁粉。
> 目标受众"段位比你低",这是对的定位——不是同行交流,是信息差输出。
> 2026-07-30 与用户共同梳理,持续增补,发一条勾一条。

## 固定口播结构(每集都套,参考杨藩讲艺术验证过的公式)

1. **开场 3 秒钩子**:直接说反差/冲突/悬念,不要自我介绍开场
2. **抛包袱**:先给一个具体的名字/数字/场景当"逗哏"
3. **抖包袱**:揭示反常识的真相/内幕
4. **拆解**:给出 2-4 条具体、可复用的原因或方法(观众截图当笔记用的部分)
5. **收尾**:一句话总结 + 关联下一条机会/下一期预告(导流)

## 选题库(共 20 个,按体系分组,()内是开场钩子草稿)

### 体系一:行业地图类(建立词汇框架,建议早发,方便后续引用)
- [ ] **展览到底分几种**:体制内 / 独立学术 / 商业(你以为的"参加展览"其实是三种完全不同的游戏)
- [ ] **机会的四种形态**:征集 / 驻留 / 奖项 / 工作坊到底有什么区别(很多人连自己申的是哪种机会都没搞懂)——**建议第 1 集,直接用 ArtPortal 真实分类讲,别人讲不出来**
- [ ] **谁在为你的展览买单**:商业画廊抽佣、独立空间收场地费、体制内免费但要背景、驻留反而给你发钱(从网站真实 funding/apply_fee/participation_fee 字段提炼)
- [ ] **策展人/艺术总监/艺委会,到底谁说了算**:不同机构类型的决策链条

### 体系二:申请实操类(最刚需,收藏率最高)
- [ ] **Artist Statement 怎么写才不像小作文**
- [ ] **CV 该给策展人看,还是给老师看**(完全是两套逻辑)
- [ ] **一份合格的申请材料清单**:驻留要 proposal、奖项要推荐信、商业展要 sales history
- [ ] **被拒的真正原因**:99% 不是"作品不够好"
- [ ] **Deadline 里的潜规则**:rolling deadline 为什么该优先申,截止日前最后一周投反而吃亏

### 体系三:生存现实类(最扎心,共鸣最强)
- [ ] **艺术家不必全职脱产**:本质是找到能持续产出的生活方式(用户已定稿话题)
- [ ] **收费驻留到底值不值得去**:免费和收费驻留的本质区别
- [ ] **"全额资助"驻留怎么鉴别真假**
- [ ] **艺术家真实收入结构拆解**:卖作品只是零头,教课/grant/驻留津贴/副业才是真正撑起生活的部分

### 体系四:信息差/内幕类(最容易出圈,反常识型钩子)
- [ ] **为什么作品普通的人也能申上顶级驻留**(今晚刷视频刷出来的真实体感原话开场):评审看的是提案不是完成度、文字叙事本身是被评能力、机构有隐性配额议程、评委口味逐年偶然、"著名"驻留有些门槛其实是经济门槛、rolling admission 的 timing 红利——**建议第 2 集,趁体感新鲜,和第 1 集的"四种形态"框架天然衔接**
- [ ] **国内外机会的信息差有多大**:多数人只知道国内那几个熟脸奖项,全球有几千个 open call(直接导流 ArtPortal)
- [ ] **"参展经历丰富"不等于"履历有含金量"**:策展人怎么看你的 CV
- [ ] **美院教的审美,进了真实策展圈子还管不管用**

### 体系五:职业路径类
- [ ] **从学生到独立艺术家中间的空窗期怎么活下来**
- [ ] **不同阶段该申什么**:什么时候冲驻留、什么时候冲奖项、什么时候攒群展履历
- [ ] **策展人是怎么"发现"艺术家的**:被动等待 vs 主动出击

## 第 1 集口播稿:机会的四种形态到底有什么区别

*[语气提示:开场快、有点"抓你痛点"的挑衅感;中段放慢,像在一条条给你划重点;结尾轻松收]*

**〔开场钩子〕**
你可能连自己申的是什么都没搞清楚。
征集、驻留、奖项、工作坊——这四个词,是不是感觉都差不多,反正就是"艺术机会"?
不好意思,这四个东西的游戏规则完全不一样。你要是分不清,材料都会准备错。

**〔抛包袱〕**
我见过太多人,拿着申驻留的作品集去投奖项,拿着投奖项的心态去申工作坊。
结果就是,材料对不上人家想要的东西,连简历都没人看完就被刷了。

**〔正文拆解〕**

第一种,**征集,英文叫 open call**。
这个最好理解——机构面向所有人公开征稿,你投,他们选,选上了通常是"你的作品能参展"。
注意,征集给你的回报,通常不是钱,是一个**曝光和参展的机会**。谁在主导?机构。他们想要什么?符合这次展览主题的作品。

第二种,**驻留,residency**。
这个是完全不同的逻辑。驻留给你的核心不是"展出",是**一段时间加一个空间**——可能是几周,可能是几个月,让你在那儿专心创作。
有些驻留会给你津贴、给你住宿,有些反而要你交参与费。这两种天差地别,我们后面单独有一集讲怎么分辨。

第三种,**奖项,award**。
这是竞赛制。你交作品或者方案,评委打分,选出赢家,给奖金、给荣誉,有时候还带后续机会,比如一个个展的机会。
奖项要求你提交的,通常是**已经完成的东西**,或者一个很具体的方案,而不是空泛的意愿。

第四种,**工作坊,workshop**。
这个跟前三个都不一样,它的核心不是"展示自己",是**学东西**。可能收费像上课一样,也可能是机构公益性质免费办的。

**〔一句话区分法,记笔记〕**
问自己四个问题:这个机会是谁发起的、谁受益?钱是我出还是他们给?结果是参展、驻地体验、奖金,还是学技能?材料要的是完成作品还是一个方案?
四个问题答完,你就知道你现在面对的是哪一种游戏,该准备什么材料。

**〔收尾〕**
今天先把这四个词的边界给你划清楚。下一期,咱们聊一个更狠的话题——为什么好多作品明明很普通的人,照样能申上那些特别出名、特别专业的顶级驻留。这事儿我今晚刷视频亲眼见了好几个,咱们下期见。

## 第 2 集口播稿:为什么作品普通的人也能申上顶级驻留

*[语气提示:开场用真实吐槽的口吻,带点意外和不忿;中段转成冷静拆解,像揭秘;结尾给出行动指南,别停在吐槽]*

**〔开场钩子,用用户原话〕**
我今晚刷视频,刷到好几个作品说实话真的很一般的人,人家申上了那种特别著名、特别庞大、特别专业的艺术驻留项目。
说实话我当时是有点意外的。但后来一想,这事儿其实完全合理——因为你以为评审在看的东西,压根不是你以为的那个东西。

**〔抛包袱〕**
你以为评审在看"这个作品完成度够不够高、技法够不够牛"。
错了。绝大多数驻留,评审真正在看的,是**你的提案**——你打算在驻留期间做什么,不是你现在这批作品好不好。

**〔正文拆解,给 5 个真实原因〕**

第一,**驻留本质是投资"方向",不是奖励"已完成的好作品"**。
机构给你的不是一个奖状,是一段创作时间。他们赌的是你接下来能做出什么,你提案讲得清楚、有意思、正好契合他们今年的策展主题,比你现在这批作品完成度高低更重要。

第二,**文字叙事能力,本身就是被评审的能力**。
Artist statement、project proposal 写得好不好,是一项独立的技能,不是作品好就自动会写。作品普通但会讲故事的人,反而更占优势——这也是为什么我们上一集之后,专门有一期要讲怎么写这个东西。

第三,**机构有隐性议程**。
地域配额、身份多样性、机构自己想拓展的话题方向、策展人的私交网络——这些东西真实存在,跟你作品好不好没关系,但真实影响结果。

第四,**评委口味是偶然的**。
同一批作品,换一批评委,结果可能完全不同。这不是客观标准,是当年那几个具体的人的主观趣味在博弈。你申一次没上,不代表作品不行,可能只是这年评委不吃这一口。

第五,**有些"著名"驻留的门槛,其实是经济门槛**。
能不能自费到场、能不能自己出材料费,这个筛选机制里,经济能力的权重被严重低估了。

**〔收尾,给行动指南,别停在吐槽〕**
所以别再死磕"我要把作品做得更牛"这一条路了。真正该花时间打磨的,是你的提案怎么讲故事、你申的这个机构今年想要什么、还有一件事——你选的到底是不是一个"门槛主要看钱"的驻留。
关注我,下一期咱们就聊,一份能打动评审的 proposal,到底该怎么写。
