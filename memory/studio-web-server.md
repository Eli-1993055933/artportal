The 网站版画室点评工具 (see [[deck-review-workflow]] second phase) runs live on 阿里云.

- **Host**: `admin@60.205.212.195` — **key-based SSH works from this Windows machine** (no password), and **`sudo -n` is passwordless**. So Claude can directly inspect *and fix* the server, not just hand the user scp/ssh commands.
- **Code**: `/home/admin/studio/{web,scripts}`. **venv python** = `/home/admin/studio/venv/bin/python` (3.11). Service = systemd unit **`studio`** (gunicorn 1 worker/6 threads on `127.0.0.1:8791`). ArtPortal (Node, port 80) reverse-proxies `/studio/*` → 8791; public URL `http://60.205.212.195/studio/` (login-gated → 401 unless authed).
- **Deploy = manual**: edits on local `D:\画室点评工具\` do NOT reach the server until `scp` + `sudo systemctl restart studio` (gunicorn caches the old module in memory until restart — a "still broken" after a code fix usually means not-yet-deployed or not-restarted).
- **Server has NO CJK fonts** (`fc-list` empty) → the tool relies on bundled `scripts/fonts/` (STZHONGS/msyh/msyhbd/Deng, ~62MB); can't count on system Noto. `deckbuild.py` font resolver is cross-platform + never-crash (bundled dir first → OS dirs → free-CJK candidates → load_default).
- **scp gotcha**: `scp -r fonts host:/…/fonts` when target already exists nests into `fonts/fonts/`.
- **Verify a build fix on the server itself**: run a tiny build via the venv python from `/home/admin/studio/web` (import deckbuild+assemble, fake numpy imgs) — proves production path without needing the login-gated HTTP flow.
- **老师 Agent (`web/critique.py`)**: critique/summary voice is research-derived (195 real-teacher语料 → `web/老师话术风格指南.json`); persona + per-subject term bank + 71-phrase AI-cliché ban + a 2-pass self-review + deterministic degender (no 他/她). Weekly summary is parent-facing, grounded ONLY in real session facts (Python pre-counts题材/日期/张数 to stop the weak model miscounting; single-session subjects forbid invented "进步了"). **Quality ceiling = model tier**: `.env` uses free `glm-4v-flash`/`glm-4-flash`; if summaries read AI-ish, the lever is upgrading `GLM_TEXT_MODEL`→`glm-4-air`/`glm-4-plus` (and vision→`glm-4v-plus`) after 充值 — interface unchanged, just edit `.env`. The teacher-review step in the web UI is the human safety net for residual tells.
- **Web features (2026-07-19)**: multi-image *append* upload with per-image date+题材; `web/roster.py` roster (`_roster.txt`, `/api/roster`) auto-aligns OCR names (only exact or unique 1-char-off); confirm page shows a live **学生×日期 matrix** (`updateGroups`, same name's works merged across images/dates, off-roster flagged orange).
- **Web features round 2 (2026-07-19)**: (1) `web/orient.py` conservative auto-rotate — only obvious sideways (ink-bbox w/h≥1.15 for portrait subjects), 0/24 false-positive on real samples; 90° *direction* is ~50% (uncertain for charcoal art) so it rotates-to-portrait + flags "⟳核对方向", manual is the backstop. (2) Canvas image editor (`/api/edit_image`,`/api/reset_image`) rotate/crop/reset, backs up `.orig`. (3) **Upload is now async** (`/api/upload` returns job → poll `/api/status` → `/api/cells/<job>`); structured progress {stage,detail,done,total,elapsed,eta} on OCR/critique/build. (4) Deck review: `/api/decks`, `/preview/<job>/<ascii>_pN.png` (PNG via `deckbuild.render_preview`, ASCII md5 keys — never Chinese filenames in URLs), `/api/rebuild_one` rebuilds one student + re-zips.
- **Speed (2026-07-20)**: everything was serial → ~1h for 20 students. Now parallel: `core.run_critiques` uses `ThreadPoolExecutor(CRIT_WORKERS=8)` for GLM calls (network-bound) with de-dup moved to a **global post-pass** (generate all → `overused_words` across the whole batch → parallel `reword_avoid` of offenders — same/better quality than the old serial avoid-list). `assemble.build_student_decks` parallelizes decks (`BUILD_WORKERS=4`); `deckbuild._pil_font` is now **thread-local** (FreeType FT_Face not reentrant); preview PNGs render at dpi=96 (screen-only; the shipped .pptx is vector text, unaffected). OCR: `ocr_names._prep_strip` downscales name strips to ≤360px, **and `_get_ocr` disables PaddleOCR 3.x's default doc-preprocessing** (`use_doc_orientation_classify/use_doc_unwarping/use_textline_orientation=False` — those doc_ori/UVDoc/textline_ori models are for full-page scans, pure waste on a tiny name strip). Combined: 1.66s→0.47s/cell (**3.5×**), results IDENTICAL, 18/18. Server split+OCR 37s→12s for 18 cells. (PaddleOCR batch predict didn't help; single instance not thread-safe so no threading.) Both worker counts are env-tunable; lower CRIT_WORKERS if the free GLM tier rate-limits (`_post` has 429 backoff).
- **Access + per-user roster (2026-07-20, decided: OPEN to all registered users)**: `STUDIO_OWNERS` is unset in ArtPortal `.env`/unit → any *logged-in* user passes the `/studio/*` gate AND sees the entry card (`/api/auth/me` sets `user.studio` via the same `owners.length===0` logic); anon →401. Do NOT set STUDIO_OWNERS to lock it down unless the teacher explicitly asks. Since it's multi-user, the roster is now **per-user**: ArtPortal proxy injects a trusted header `x-studio-uid = me.id` on `/studio/*` (and `delete`s any client-supplied one first — 8791 is internal-only so it's trustworthy; server.mjs backup at `server.mjs.studiobak`). `app.py._uid()` reads it; `roster.py` stores `web/_rosters/roster_<uid>.txt` and returns **[] when unset** (never leaks another user's list / the old 20-name DEFAULT). `_run_split_phase(uid)` snaps names with the uploader's own roster. The teacher must re-enter their class list once under their own account (old shared `_roster.txt` is only a no-uid fallback that won't trigger behind the proxy).
- **Configurable branding (2026-07-20)**: PPT school/class/teacher (原写死 南海艺高/三组/张智涵) now come from upload-form fields `teacher/school/klass` → stored in `meta.json.brand` → threaded `core.build_decks(brand)`→`assemble.build_student_decks/_build_deck(brand)`→`deckbuild.layout_*(name, brand=)` (`_BRAND` default merge; also has `studio/term/dept` defaults not yet exposed). Per-user remembered via `roster.load/save_profile(uid)` (`_rosters/profile_<uid>.json`, `/api/profile`), form auto-prefills. Missing fields fall back to defaults.
- **ArtPortal auth rate-limit fix (2026-07-20)**: friend on 4G got "尝试太频繁,请稍后再试" registering — `lib/auth.mjs`'s `authLimited(ip, max=10, 10min)` keyed register+login on the SAME bare-ip bucket, and mobile CGNAT shares one IP across many users. Fixed: separate buckets `reg:ip`=40/10min (email-code-gated, safe to be generous), `login:ip`=30/10min, `codeip:ip` 8→20/10min. Backup `lib/auth.mjs.ratebak`. Restarting artportal also clears the in-memory `authHits` Map (instant unblock).
- **Dev gotchas (bit me hard)**: backgrounded local flask leaves **zombie instances holding :8790** so new code silently doesn't take — kill by port-PID (`netstat|taskkill //PID`) then curl-verify a route before testing. Endpoints `abort(404)` on empty/invalid job_id (via `_jobdir`), so a `{}` probe 404s *by design* — not a missing route. Shell quoting/encoding corrupts Chinese in curl bodies/URLs — use `--data @file` and ASCII filenames.
