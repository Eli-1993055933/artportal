# 激光雕刻分板（水印木刻套色）

把已确认的风格成品图拆成"一色一版"的黑白雕刻文件，供厂家激光雕刻、逐版套印。

## 标准协作流程（用户约定）

1. 用户发照片 → 先用 **art-style-01-phil-greenwood**（或其他已确认风格）出图，成品存桌面
2. **等用户确认图片没问题**（不要未确认就分板）
3. 用户确认后，对确认图执行本技能分板，成品同样存桌面（默认 `~/Desktop/版画激光分板/`）
4. 汇报色版构成，提醒打样建议

## 网络与浏览器红线（2026-10-03 用户明确要求）

1. **分板 / 放大等图片处理一律纯本地**（Python + PIL/numpy/scipy），不起本地 HTTP 服务、不开浏览器、不调任何图床/外链。
2. **图片文件绝不上传**：成品只写桌面（git 仓库之外，git 根本追踪不到）。唯一允许的网络动作是 `git push` 代码/文档（.py/.md 等文本），推送前要能说清推了哪几个文件；**禁止把 png/jpg 加入提交**。
3. **浏览器自动化只在 art-style 生图的鉴权通道短暂使用**，用完立即关闭本地服务与标签页，不许留后台 http.server（残留服务会和用户的其他浏览器任务抢使用权）。开工前先 `ps`/`lsof` 查有无残留服务，有就先停掉。
4. 向用户汇报时主动说明：本次图片**只存在本地哪个目录**、git 推了什么（明确无图），不使用"上传/已发"等含糊措辞。

## 最小线宽（甲方硬性要求，2026-10-03 规定）

厂家三条要求实为同一物理指标的三种表述，**取最严**：

| 工具 | 阈值 | 换算 |
|---|---|---|
| Illustrator | ≥ 2pt | 0.706 mm |
| Photoshop | ≥ 10px（按 300DPI） | **0.847 mm ← 最严** |
| CorelDRAW 18 | ≥ 0.6mm | 0.600 mm |

脚本按 `--min-mm 0.85` 执行（0.85 ≥ 最严档 0.847mm）。像素阈值随工作分辨率换算：长边 400mm 时为
**16–18px @463–521DPI ≈ 0.88mm**，折算到 300DPI 交付稿约 10.4px（仍满足 PS ≥10px 硬要求）。
画面内不存在低于该值的墨线——细密飞尘颗粒与细排线会被抹掉，这是激光雕刻的物理极限，**必须在汇报时如实告知并量出并掉比例**。

### 算法：圆盘保形开运算（v2，2026-10-03 重做）

**绝不能用"降采样 / 网格量化"去凑参数**——那会把整幅画变成 k 像素方块（马赛克），画面直接废掉。
v1 曾用 `k×k 方形核 + k 网格量化兜底`，实测输出全是 11px 方块与孤立碎点，已被用户否决，禁止回退。

v2 用**圆盘结构元**（`scipy.ndimage.distance_transform_edt` 实现）：

- `erode_disk(M,r)`：保留到最近背景像素距离 **> r** 的像素（`>` 与 `dilate_disk` 的 `<= r` 严格对偶，否则开运算不幂等、实测会误判为 0）
- `open_disk(M,r) = dilate_disk(erode_disk(M,r), r)`：结果满足"墨区任一点都落在某个直径 2r 且完全含于墨区的圆盘内"⇔ **墨区最小宽度 ≥ 2r**
- `close_disk(M,r) = ~open_disk(~M, r)`：并掉窄于 2r 的空白缝（**仅在 `open_disk(结果,r)==结果` 成立时才采用**，保证不破坏线宽）
- 达标笔画与色块**一点不动**，只有不足 2r 的细线、碎点被整条圆滑移除；边界保持原有曲线，不产生方块
- 实测校验用开运算不变性：逐级加大 r，取仍满足 `open_disk(M,r)==M` 的最大 r，报 `2r` 对应的 mm

抗锯齿与矢量：形态学在 `RES=2` 倍超采样分辨率上做，降采样时取 RES×RES 均值得到 1px 抗锯齿过渡；
同时用 `skimage.measure.find_contours` + RDP 简化 + Catmull-Rom 转三次贝塞尔，每版另出一个 SVG，矢量边缘放大任意倍率都无锯齿。

**幂等性自测（改代码后必跑）**：
```python
import numpy as np, plate_sep as P
m = (np.random.default_rng(1).random((600,800)) > .5)
assert np.array_equal(P.open_disk(P.open_disk(m,11),11), P.open_disk(m,11))
```

### 成品尺寸决定细节保留量（重要）

最小线宽是**绝对毫米值**，而画面细节占多少毫米取决于成品尺寸——**成品越大，同一处细节的毫米数越大，被抹掉的越少**。
标准尺寸已定：**长边 400mm / 300DPI**（用户 2026-10-03 定）。同批 6 张（源图 1216~1368px）实测：

| 作品 | 画面 | 细部并掉 |
|---|---|---|
| 03 民宿 | 400×300mm | 15% |
| 04 民宿3 | 400×225mm | 17% |
| 06 玫瑰（竖图） | 225×400mm | 20% |
| 05 风信子花田 | 400×300mm | 23% |
| 02 雪景 | 400×225mm | 24% |
| 01 田间小路 | 400×300mm | 29% |

规律：源图细节越碎（野花、草叶肌理）并掉越多，纯色块与粗轮廓几乎不掉。
**要少丢细节就整体加大长边**（细线同步变粗更容易达标），全套餐版须同倍率等比缩放、规矩线同步。
仍须向用户确认厂家 PS 文档的实际 DPI：若厂家在 150DPI 文档里量 10px，则要求变成 1.69mm，需 `--min-mm 1.69` 重做。

## 已有色版线宽不达标：等比放大（不改内容）

当手上已有一批**干净但线太细**的色版（例如外部/早期输出，最细墨线只有 2px≈0.17mm），
又要求"内容一点不改"时，唯一物理可行的办法是**整幅等比放大**——最小线宽是绝对像素/毫米值，
放大 S 倍则线宽同步放大 S 倍，图形一根不动。放大倍数 = 目标线宽 ÷ 现有最小线宽。

```bash
/tmp/plateenv/bin/python scripts/upscale_plates.py 源目录/0[1-6]_*.png 源目录/00_叠印预览.png \
  --out "目标目录" --scale 5 --target-px 10 --dpi 300
```

- `--scale`：等比倍数（默认 5）；`--target-px`：放大后要求的最小线宽 px（默认 10 = 厂家 PS 硬要求）
- 放大前先做一次小半径圆盘开运算，只清掉放大后会不达标的 **1~2px 抗锯齿毛刺**（阈值化副产物，不是画面内容），
  边界用双线性重采样，平滑无锯齿；**不做任何降采样/网格量化**
- 实测最小线宽在**源尺度**量完再乘倍数（亿级像素成品图上直接跑距离变换会爆内存）
- 规矩线随整幅一起放大，与其他色版坐标仍一致；须整套同倍率，不可单张处理
- 放大后必须复核：像素数与 mm 尺寸、实测最小线宽 ≥ `--target-px`、无反马赛克
- `分板示意.png` **不要盲目放大**：它是给人看的说明图，页首若写着旧尺寸（来源于另一分辨率），放大只会把错误数字一起放大——应重制而非放大

## 执行

```bash
/tmp/plateenv/bin/python scripts/plate_sep.py 图1.jpg [图2.jpg ...] \
  --out "/Users/Eli/Desktop/版画激光分板" --colors 7 --dpi 300 --min-mm 0.85 --width-mm 400
```

`--width-mm` 指的是成品**长边**（默认 400，用户 2026-10-03 定）：横图长边=宽，竖图长边=高。
这样一套作品长边统一 400mm、全部 300DPI；**若按"宽"给竖图，会被撑成 400×712mm 的超高巨幅且掉到 195DPI**（已实测，勿再犯）。
成品越大，同一细节占的毫米数越多、能保留的细节越多；要改尺寸就整套一起改。

- 写桌面会被沙箱拒绝，该 Shell 调用必须 `dangerouslyDisableSandbox: true`
- `--colors` 是含纸色的聚类数：默认 7 → 实际约 6 块色版。画面颜色特别丰富可给 8-9（多一块版多一份雕刻成本，默认别动）
- 支持任意张图批量处理，自动编号、自动从文件名剥离"版画/风格"等后缀做目录名
- 脚本自动抹右下角 AI 水印（按相对比例定位），换位置的水印需手工确认是否抹净

## 输出（每套一个目录）

- `01_色名_HEX.png …`：300DPI 抗锯齿灰度色版（黑 0=上墨区，白 255=刻除区，边界 1px 平滑过渡），四角带十字套印规矩线
- `01_色名_HEX.svg …`：同版矢量文件（贝塞尔曲线，AI/CDR 直接可用，放大无锯齿，线宽以 mm 精确可控）
- `00_叠印预览.png`：分色重建效果（抗锯齿），与原图对照验收用
- `分板示意.png`：每版彩色区域 vs 黑白版对照（给用户目验）
- 根目录 `分板清单.csv`（色名/HEX/RGB/覆盖率/细部并掉%/实测最小线宽/尺寸）、`厂家制作说明.txt`

## 验收（必须目验后再交付）

0. **合规硬门槛**：读 `分板清单.csv`，每块版的"实测最小线宽mm"必须 **≥ 0.85**（最严档 = PS 10px@300DPI = 0.847mm；实际执行值随成品尺寸与工作 DPI 变化，以 CSV 与示意页标注为准），任何一版低于此值**禁止交付**，回查 `open_disk` 的对偶性与幂等性
1. **反马赛克硬门槛**：Read 任一色版 PNG，画面必须是连续曲线与圆滑斑点——**一旦出现 k 像素方块、方格感、条带，说明误用了降采样/量化，立即重做**
2. Read 每套的 `分板示意.png`：叠印预览应与原图结构一致；确认并掉比例可接受、没有一整版颜色奇怪/漏色
3. Read 最深色版 PNG：四角规矩线完整、右下水印未残留
4. 纸色判定：近白色层自动留纸不印（高明度 L≥88 且低彩度≤15）；雪景/大面积白底作品会少一层，属正常
5. 色名靠 Lab 自动命名，偶有偏差以 HEX 为准，必要时手工改文件名后同步 CSV

## 工艺要点（写进厂家说明的内容，别漏）

- 浅色先印（01）→ 深色后印（06），最后一色是主轮廓暗部
- 纸白色留纸，用暖白/米白纸，不用冷白铜版纸
- 所有版同尺寸同倍率，规矩线坐标一致，同一靠身定位
- 边缘为 1px 抗锯齿过渡：纯凸版可直接阈值 128 二值化；灰度雕刻可调刀深
- 细密黑点是版画肌理不是噪点；建议先做对比最强的一套打样

## 已知边界

- 硬分色（每像素只属一版，无叠印混色），适合水印木刻/激光胶板；若用户要真丝网印的半色调网点，需另做 halftone
- 提供 PNG（300DPI 抗锯齿）+ SVG（矢量贝塞尔）两种格式；DXF 尚未做，厂家要 DXF 时再补
- **"保形"不等于"保全部细节"**：低于最小线宽的细排线/飞尘颗粒只能整条抹掉（或整体放大成品尺寸来保住），
  这是过程物理极限，不是算法缺陷；汇报时务必给尺寸-并掉率对照表让用户取舍
