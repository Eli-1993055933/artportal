# 老版主站备份(2026-07-22 退役)

v0.77.0 起,地球界面(原 globe-test.html)转正为主站 `site/index.html`,
老版列表式主站整体退役,文件备份于此,**不再部署、不被现网引用**。

## 内容
- `index.html` — 老版主站页面(退役时最后状态,含未提交的最后修改)
- `js/` — 老版全部前端模块(auth/profile/works/notify/publish/weekly 等 17 个)
- `css/app.css` — 老版全部样式

## 想看一眼怎么办
老版页面引用的是相对路径 `js/`、`css/`,并从 `data/`、`assets/` 取数据与图片。
把本目录三样临时拷回 `site/` 下(改名 `index-old.html` 以免顶掉现网首页),
用本地静态服务打开即可;看完删掉,别提交、别部署。
